**9. High — Primitive constructor/cast validation admits invalid Builder values. Reproduced.**

The documented `b = Builder(64); b += "A"; io::out $ +b` compiles, then terminates with SIGSEGV. Reproduction (`builder_constructor/main.dva`, archived with the report). `{64}` is the actual Builder allocation syntax.

Primitive-name calls receive their target type without a general legality or arity check ([annotate.dva:2828](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/src/annotate.dva#L2828)); the generic cast fallback can merely relabel an unchanged value ([expr.dva:7306](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/src/codegen/expr.dva#L7306)). This allows a scalar to become an invalid Builder representation. The arity probe (`cast_arity/main.dva`, archived with the report) also shows `Int(1, 2)` silently returns 1 and `Int()` returns 0. Extra arguments should not silently disappear. Enforce a legal conversion matrix and explicit constructor arities before LLVM generation. Correct [the Builder reference example](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/doc/reference/types/builder.qmd#L19) immediately.
