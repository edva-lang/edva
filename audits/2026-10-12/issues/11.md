**11. Design contract — Builder ownership is described as linear, but implemented as shared mutable descriptors. Reproduced.**

[GRAMMAR.md:1288](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/GRAMMAR.md#L1288) promises aliasing is a compile error, and [GRAMMAR.md:1328](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/GRAMMAR.md#L1328) promises E3060 for any use after freeze. The [Builder page](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/doc/reference/types/builder.qmd#L94) repeats the invalidation promise.

The probe (`builder_alias/main.dva`, archived with the report) aliases `c = b`, appends through c, freezes b, appends again through b, and freezes c. It compiles and prints `AB`, then `C`. Freeze resets a shared descriptor to zero ([main.dva:853](https://github.com/edva-lang/edva/blob/bc20a35ba2dd351bb0c891797a33d1ec8ae74940/src/codegen/main.dva#L853)); subsequent append is accepted. This probe does not demonstrate mutation of an already-frozen String. It demonstrates that the advertised uniqueness and use-after-consume checks do not exist in this path. Gitea #84 already chose reusable shared descriptors with detach/reset. This issue aligns the remaining documentation with that accepted contract; it does not request a change to linear ownership.

Audit: 2026-10-12, finding 11, Edva checkout `bc20a35ba2dd351bb0c891797a33d1ec8ae74940`. Local project report: `audits/2026-10-12/report.md`. Source permalinks above identify the audited GitHub revision; this Gitea repository is the existing Edva issue tracker.

**Reproduction: builder_alias**

```dva
#use io
b = {16}
b += "A"
c = b
c += "B"
io::out $ +b
b += "C"
io::out $ +c
```

Observed exit status: `0`.

```text
AB
C
```
